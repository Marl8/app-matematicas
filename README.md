## Description

Backend en Nest Js del proyecto app de Matemáticas para Innova Lab.

## Project setup

```bash
$ npm install
```

## Compile and run the project

```bash
# development
$ npm run start

# watch mode
$ npm run start:dev

# production mode
$ npm run start:prod
```

## Run tests

```bash
# unit tests
$ npm run test

# e2e tests
$ npm run test:e2e

# test coverage
$ npm run test:cov
```

## Deployment

```bash
$ npm install -g @nestjs/mau
$ mau deploy
```

## Dependencies

- TypeOrm
- Jwt
- Passport
- bcrypt
- class-validator
- Swagger
